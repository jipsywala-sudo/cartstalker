# Campus Golf Cart Live Tracker

A real-time, responsive web application designed for students and staff to track campus shuttle golf carts. View live vehicle locations, estimated arrival times (ETA), route maps, and seat availability at a glance.

---

## 🚀 Features

* **Live Shuttle Tracking**: Interactive map interface showing real-time positions and movement of active golf carts.
* **ETA & Route Info**: Displays accurate estimated arrival times for upcoming stops across predefined campus routes.
* **Seat Availability Indicator**: Real-time status showing open vs. occupied seats on approaching carts.
* **Stop Selector**: Quickly find nearby cart pick-up/drop-off points across the campus.
* **Route Schedules & Frequencies**: View complete route details, operating hours, and shuttle loop intervals.
* **Fully Responsive**: Optimized mobile UI for quick checking while walking between academic blocks.
